\# TeklaFirstTool



Small Windows Forms tool that talks to Tekla Structures 2026 (Student, US environment).



\## Buttons

\- Connect to Tekla: shows connection status and model path

\- Create Beam: places a W16X40 beam (A992), 6000 mm long

\- Create Column: places a W12X26 column (A992), 4000 mm high



\## How to run

1\. Open Tekla with a model.

2\. Open the .slnx in Visual Studio, set x64, press F5.
